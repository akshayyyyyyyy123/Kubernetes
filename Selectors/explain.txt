The biggest improvement ReplicaSet made over ReplicationController is set-based label selectors.

1. Equality-based selectors
  - This is what ReplicationController supports and ReplicaSet supports it too.
  - Example:
  
      selector:
        matchLabels:
            app: nginx
            env: prod

  - Pods:
        Pod1                        Pod2                        Pod3
      app=nginx                    app=nginx                  app=apache
      env=prod                     env=dev                    env=prod


  - ReplicaSet selects ✅ Pod1
  - Because: app = nginx AND env = prod

------------------------------------------------------------------------

2. Set-based selectors
  - Instead of checking for one exact value, you can define a set of acceptable values.
  - ReplicaSet uses: matchExpressions:
  - There are four operators : In, NotIn, Exists, DoesNotExist

  A. In
    - The label value must be one of the listed values.
    - Example:
                matchExpressions:
                - key: app
                  operator: In
                  values:
                    - nginx
                    - apache
                    
    - Pods: 
    Pod1                  Pod2                Pod3
  app=nginx             app=apache          app=redis

   - Selected: ✅ nginx , ✅ apache , ❌ redis
   - Equivalent to: app = nginx OR app = apache

------------------------------------------------------------------------

   B. NotIn
    - Select everything except these values.
    - Example:
                matchExpressions:
                - key: env
                  operator: NotIn
                  values:
                    - dev
   - Pods: 
    Pod1                  Pod2                Pod3
  env=prod              env=dev             env=test 

  - Selected: ✅ prod, ✅ test, ❌ dev

------------------------------------------------------------------------

  C. Exists
    - I don't care about the value. The label key must simply exist.
    - Example:
            matchExpressions:
            - key: version
              operator: Exists
    - Pods: 
    Pod1                  Pod2                Pod3
  version=v1             version=v2           

   - Selected: ✅ Pod1, ✅ Pod2, ❌ Pod3

   - Notice that ReplicaSet doesn't care whether the value is v1, v2, or anything else—only that the version label is present.

------------------------------------------------------------------------

 D. DoesNotExist
   - The label key must not be present.
   - Example:
            matchExpressions:
            - key: debug
              operator: DoesNotExist
    - Pods: 
    Pod1                  Pod2                Pod3
  debug=true                        

   - Selected: ✅ Pod2, ✅ Pod3, ❌ Pod1

------------------------------------------------------------------------------------------------------------------------------------------------

ReplicationController supports only equality-based selectors (key=value). 

ReplicaSet extends this by supporting both equality-based selectors (matchLabels) and set-based selectors (matchExpressions) using the
In, NotIn, Exists, and DoesNotExist operators.
